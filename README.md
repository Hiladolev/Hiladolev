### 🛠️ Featured Projects

#### 📄 [Exam Shuffler](https://github.com/Hiladolev/exam-shuffler) *(in progress)*
A tool that takes a master-copy exam PDF (where the first answer is always correct) and automatically generates a randomized version — using OCR, automatic question-boundary detection, and image cropping to preserve tables and diagrams.
`Python` `Streamlit` `OCR` `PDF Processing`

#### 🧳 Trip Planning Agent *(in progress)*
An AI agent that consolidates scattered trip recommendations (text, screenshots, map pins) into a day-by-day itinerary with budget tracking — built from scratch using tool-calling, not just a wrapper around a chat prompt.
`Python` `FastAPI` `Claude API` `Agents`
